# Security Policy

## Reporting a vulnerability

If you discover a security issue in MMA Analyser, please **do not open a public GitHub issue**.

Report it privately by email to: **ms.bousalem@gmail.com**

Please include:

- A clear description of the vulnerability
- Steps to reproduce
- Affected files/paths (if known)
- Potential impact
- Suggested fix (optional)

## Response process

- We will acknowledge receipt as soon as possible.
- We will validate and triage the report.
- A fix will be prepared and released when confirmed.
- Public disclosure should wait until a fix is available.

## Scope

This policy applies to this repository and maintained releases of MMA Analyser.
